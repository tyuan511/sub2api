# Image Studio 预设尺寸核对

核对日期：2026-09-05。范围为当前 GPT Image 2 的 8 种固定比例、24 个预设，以及自动模式、旧版 GPT Image 尺寸和历史兼容性。

## 结论

按用户确认的命名，菜单、选中摘要和历史记录使用 1K／2K／4K 预设档位名。具体请求尺寸显示在宽高输入框和悬停提示中；档位名称不代表所有比例都有相同边长。自定义尺寸保留自身像素，不高亮一个不匹配的预设。

24 个当前预设均满足官方的像素、边长、比例和 16 像素对齐限制。4K 档提供可用的高分辨率选项，不承诺所有比例都到达模型上限。

16:9 默认 1792×1008、9:16 默认 1008×1792，沿用用户已确认的 16 像素对齐方案。界面中 1:1 的默认尺寸仍为 1024×1024。

## 模型限制与 4096×4096

[OpenAI 官方图片生成指南](https://developers.openai.com/api/docs/guides/image-generation#size-and-quality-options)要求 GPT Image 2 最长边不超过 3840，两边均为 16 的倍数，最长边与最短边之比不超过 3，总像素处于 655360–8294400。

- 4096×4096 = 16777216 像素，同时超过边长和总像素上限，不能作为当前模型的原生请求预设。
- 2880×2880 = 8294400 像素，达到方形的总像素上限；它是 2880 像素方图，不是 4096 像素方图。
- 3840×2160 和 2160×3840 均为 8294400 像素，满足限制。
- 不进行自动拉伸、放大、裁切或偷偷降低请求尺寸。

## 自动与旧记录

- 比例菜单不再提供自动选项，默认 1:1。请求层保留自动比例省略 `size` 的兼容能力，历史数据不修改；编辑旧自动记录时回到 1:1，提示比例不可用并等待用户提交。
- GPT Image 1／1.5 的固定预设为 1024×1024、1536×1024、1024×1536，默认 1:1。
- 不修改历史数据库中的预设 ID 或原始尺寸。继续使用 `1K`／`2K`／`4K` 标识和展示预设档位。
- 已移除的 4:5／5:4 不重新加入新建选项；其 6 个历史预设仍合法，保留历史数据兼容性。
- 历史有 `size` 时，在档位的悬停提示中显示已记录的请求尺寸。
- 价格继续按请求真实尺寸的最长边匹配现有分组计费档位，与界面的预设名称分开。

本次核对验证参数和本地交互，不调用真实付费生图渠道。
